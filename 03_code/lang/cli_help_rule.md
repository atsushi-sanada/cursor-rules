# 🛠️ コマンドラインツール用ヘルプメッセージ実装ガイドライン（Cursorルール）

このドキュメントは、Cursorプロジェクト内で使用される **CLIツール・スクリプトのヘルプ表示実装**における共通ルールを定めたものです。

---

## ✅ 基本方針

- `--help` および `-h` の2形式でヘルプを表示できること
- 引数なしで起動された場合はヘルプを自動表示すること（推奨）
- 各引数の **意味・形式・デフォルト値** を明示すること
- **実行例（Usage）** を明示すること
- ヘルプ表示は **標準出力（stdout）に出力**
- 表示は **80〜100文字以内で折り返し表示されること**（読みやすさ）

---

## ✅ 表示項目テンプレート

```text
Usage:
  mytool [options]

Options:
  -i, --input <path>        入力ファイルのパス
  -o, --output <path>       出力ファイルの保存先（省略時は ./out）
  -v, --verbose             詳細ログを表示する（デフォルト: off）
  -h, --help                このヘルプを表示

Examples:
  mytool -i data.csv -o result.json
  mytool --verbose
