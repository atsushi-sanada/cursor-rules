# BATファイル作成ルール（Shift-JIS運用版）

## ファイルフォーマット

* **エンコーディング**：Shift-JIS（ANSI）で保存すること（UTF-8は禁止）

  * 特にBOM付きUTF-8は、先頭に不可視文字が入り**誤動作**の原因となるため厳禁。
* **改行コード**：CRLF（Windows標準）で統一すること。
* **コードページ変更は不要**：`chcp 65001 >nul` は使用しない。

## Pauseコマンド（親子プロセス制御）

他の `.bat` から `call` されたときに不要な停止を防ぐため、以下の形式で記述：

```bat
echo %CMDCMDLINE% | find /i "%~nx0" >nul && pause
```

* `%~nx0`：このバッチのファイル名
* `%CMDCMDLINE%`：コマンドライン呼び出し文字列

## コメント記述ルール

* `::`（ダブルコロン）または `echo` を使用する。

  * `REM` は**Shift-JIS以外では文字化けする可能性**があるため禁止。
* コメントの使い分け：

  * **処理説明** → `echo`
  * **補足メモ・無効行** → `::`

### 使用例

```bat
:: 仮想フォルダを削除
echo Removing temp folder...
rmdir /s /q .\temp
```

## 禁止事項

| 禁止項目             | 理由                        |
| ---------------- | ------------------------- |
| UTF-8での保存        | 文字化け、BOM誤動作の元             |
| `chcp 65001` の使用 | PowerShell等との混在環境で不安定化    |
| `REM` によるコメント    | エンコーディング依存で化けるケースあり       |
| 複雑な処理の長文化        | 保守困難になるため、5〜30行で関数単位に分割推奨 |
