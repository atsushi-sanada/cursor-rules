# bat作成ルール

## ファイルフォーマット
- BAT ファイルは UTF-8 扱いとして、冒頭に以下を宣言してください
```
@echo off
chcp 65001 >nul
```
- 改行コードはCRLFで統一してください

## Pauseコマンド
- pauseコマンドについて、以下のようにして他のbatからCallされたときは止まらないようにしてください
```
echo %CMDCMDLINE% | find /i "%~nx0" >nul && pause
```

## コメント
- 文字化けしやすいのでRENコマンドのコメントは禁止
- コメントが必要な処理はechoと:: を代用する。
	- 処理を記載するときはechoを使用する
	- 可読性のために捕捉が必要な処理は:: を使用する
